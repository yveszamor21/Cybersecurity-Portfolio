# 3 - Network Security

Network security hardening and configuration projects from DeVry coursework.

## Projects

### 3.1 - Router Wireless Security
Hardened TP-Link router: WPA3 encryption, MAC filtering, disabled WPS, firmware updates.

### 3.2 - IP Address DHCP Management
Configured static/dynamic IPs, managed Ubuntu IP settings via terminal, resolved connectivity issues.

### 3.3 - Subnetting Loopback Setup
Designed 25-subnet configurations with valid ranges, verified through ping tests and troubleshooting.

### 3.4 - Network Topology Testing
Created detailed Visio network diagram, validated connectivity across devices to ensure routing accuracy.

- Router security hardening
- WPA3 encryption

- Network hardening
