# 4 - Intrusion Detection & Analysis

Intrusion detection projects from DeVry Infrastructure Security course.

## Projects

### 4.1 - Intrusion Analysis Wireshark
Identified OS fingerprinting techniques, analyzed suspicious ICMP and TCP traffic through TTL and flag inspection.

### 4.2 - Snort Rule Creation Testing
Wrote and tested custom IDS rules to detect ping activity and XMAS scans, validated alerts through packet analysis.

### 4.3 - Secure Communications SSL/TLS
Decrypted and analyzed SSL traffic to verify GET requests and secure stream integrity.

### 4.4 - System Access Monitoring
Used Linux tools, Process Hacker, and Process Monitor to detect anomalies, manage services, and implement time-based firewall rules.

**Skills Demonstrated:**
- Wireshark packet analysis
- Snort IDS
- Network traffic monitoring
- ICMP/TCP analysis
- Threat detection
- SSL/TLS analysis
