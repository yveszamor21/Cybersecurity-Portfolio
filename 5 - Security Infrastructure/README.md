# 5 - Security Infrastructure

Security infrastructure implementation from DeVry Information System Security course.

## Projects

### 5.1 - Data Encryption Implementation
Implemented asymmetric key encryption for secure file transmission using public/private key pairs.

### 5.2 - Network Scanning Analysis
Performed vulnerability scans with Nmap and Nessus, used Wireshark and NetCat for packet and traffic analysis.

### 5.3 - Access Controls MFA
Configured multifactor authentication with Google Authenticator to strengthen system login procedures.

### 5.4 - Policy Firewall Management
Developed a BYOD policy and applied iptables firewall rules to enforce access control and network protection.

**Skills Demonstrated:**
- Nmap scanning
- Nessus vulnerability assessment
- Encryption implementation
- Access controls
- MFA configuration
- Firewall rules (iptables)
- BYOD policy development
