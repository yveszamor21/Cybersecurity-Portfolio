# 7 - Network Analysis

Network traffic analysis projects.

## Projects

### 7.1 - Network Sniffing with Wireshark

**Description:**  
Captured and analyzed live network traffic using Wireshark, identified protocols, extracted key data, and demonstrated packet-level inspection techniques.

**Skills Demonstrated:**
- Wireshark packet capture
- Protocol analysis
- Network forensics
- Packet inspection
- Data extraction
- Traffic pattern analysis

**Learning Outcomes:**
- Understanding network protocols (TCP/IP, HTTP, DNS)
- Identifying normal vs. suspicious traffic
- Packet-level troubleshooting
- Network security monitoring
